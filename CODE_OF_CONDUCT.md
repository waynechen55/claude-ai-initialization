# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and constructive. Critique code and ideas, not people.
- Assume good faith; ask before concluding.
- No harassment, insults, sexualised language or imagery, or publishing
  anyone's private information — including credentials or internal host names
  that appear in logs you share.

## Scope

This applies in every project space — issues, pull requests, discussions —
and when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/waynechen55). Reports are handled confidentially.
Maintainers may remove, edit or reject contributions, and temporarily or
permanently ban contributors, for behaviour they deem inappropriate, following
the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
